# Company-to-basic-industry mapping: provenance, completeness, and staged ingestion

## Current status — 10 November 2026

**The Basic Industries discovery screen is still an incomplete, sample-based research tool.**
This PR expands the classification master and adds a reproducible review process;
it does **not** assert that all ~452 thematic symbols (or every NSE-listed
company) has already been officially assigned to an industry.

- **188** candidate basic-industry labels were supplied to Phase 2. NSE's
  published methodology describes **197** basic industries; those are not
  equivalent counts and this catalog is **not a complete official master**.
- The code/parent dictionary has been expanded by checking the July 2023
  NSE classification structure, but labels without checked codes remain pending.
- The seed company master contains **30 individually source-linked records**;
  **24** of those match the current **452 unique themed tickers** as of this
  code change. Other verified names may appear only in the latest saved
  snapshot (if it contains them); the actual coverage report is computed
  dynamically, without treating a theme as company-industry evidence.
- Remaining companies are listed in the **Classification coverage** panel
  as "Needs classification review" with links for individual NSE lookup.
- Industry returns, breadth, and "rankable" signals describe the **verified
  sample only**, and should not be treated as complete-market industry indices.

## Why the master cannot simply be generated by looking at thematic baskets

NSE Indices' industry taxonomy is a four-level classification determined
primarily by company business/segment revenue, not by its theme or its name.
Official classifications may be updated after annual reports and mergers.

The **public NSE structure PDF** lists *industry codes and definitions*, but
does not supply a comprehensive, dated ticker/ISIN-to-industry roster.
NSE separately provides constituent and other reference-data services under
subscription/licensing arrangements. We must not manufacture classifications
or publish licensed bulk data without appropriate usage rights.

References:
- Methodology: https://www.nseindia.com/static/products-services/industry-classification
- Published July 2023 structure:
  https://nsearchives.nseindia.com/web/sites/default/files/inline-files/nse-indices_industry-classification-structure-2023-07.pdf
- NSE constituent data subscriptions:
  https://www.nse.in/static/nse-indices/index-data-subscription

For the complete official mapping, ask **indices@nse.co.in** about a
permitted company-level basic-industry dataset, its effective date, ISIN and
symbol fields, and redistribution/storage rights. If the user already has
such a dataset, it can be validated locally (no external upload required).

## Using the new coverage view

1. Deploy this PR to Vercel, open **Basic Industries**.
2. Expand **Classification coverage — Map every stock to its basic industry**.
3. Review total symbols (the union of the existing thematic universe and
   the currently loaded saved-market snapshot) and source-verified mappings.
4. Filter for **Needs classification review**; search any ticker, and use
   **Check NSE** to find and manually confirm the official basic industry.
5. Click **Export full audit CSV** to export every symbol, verification
   state, current theme membership, snapshot presence, source and review date.

The audit is a *work queue*, **not** official NSE sector composition data.

## Importing an authorized classification CSV safely

Run locally from the repository root:

```bash
# Print exact coverage of the saved-symbol plus thematic union (no writes):
npx tsx scripts/review-basic-industry-import.ts --coverage

# Optionally save the current audit as CSV:
npx tsx scripts/review-basic-industry-import.ts --coverage --out /tmp/current-audit.csv

# Stage a data provider's properly licensed file for review:
npx tsx scripts/review-basic-industry-import.ts --input /private/nse-industry-master.csv --out /tmp/classification-review.csv
```

Input CSV must have (case-insensitive, common aliases accepted):
```csv
Symbol,ISIN,BasicIndustryCode,BasicIndustry,SourceUrl,SourceDate
ITC,INE154A01025,IN040107001,Diversified FMCG,https://www.nseindia.com/get-quote/equity/ITC/Itc,2026-11-09
```

Rows are classified into such states as `ready-for-human-review`,
`already-verified`, `unverified-industry-code`, `invalid-isin`,
`code-name-mismatch`, `duplicate-conflict`,
`existing-mapping-conflict`, or `outside-current-universe`.

**A file that passes automated checks is NOT automatically approved.**
The script never writes to `src/data/basicIndustryMappings.ts`, never
downloads external data, and does not trigger the market-data collector.
A reviewer must confirm the stock's current NSE symbol and ISIN, revenue
classification, code, source license and effective date before promoting a
record into the versioned source-linked mapping.

### Manual promotion requirements

For each reviewed record: exact NSE symbol (and ISIN if available),
official basic-industry label and code, direct evidence URL (or authorized
provider source), as-of/review date, and a conflict/reclassification check.
No transfer of proprietary CSV contents into a public repository without
rights to redistribute. Update the verified mapping source only after review,
then rerun:

```bash
npm run lint
npx tsx --test src/utils/basicIndustryCoverage.test.ts src/utils/basicIndustryAnalytics.test.ts
npm run build
```
